06 · Lógica de cálculo de gasto energético

Cardio: MET × peso × tiempo

// activity.js — Compendium of Physical Activities (Ainsworth et al.)
const MET = {
  natacion:     { baja: 4.5, moderada: 6.0, alta: 8.0 },
  caminata:     { baja: 2.5, moderada: 3.5, alta: 4.5 },
  running:      { baja: 8.0, moderada: 10.0, alta: 12.0 },
  yoga:         { baja: 2.5, moderada: 3.0, alta: 3.5 },
  sauna:        { baja: 1.0, moderada: 1.1, alta: 1.2 },
  sexo:         { baja: 1.3, moderada: 1.8, alta: 2.8 },
  // ... 17 tipos total
};

kcal = MET[tipo][intensidad] × pesoKg × (duracion_min / 60)

Fuerza: modelo híbrido compound/isolation × intensidad × volumen

VariableCompoundIsolation
MET base5.03.5
Min/set estimados4.5 min2.5 min

≥40% BW (100kg+ en 125kg)×1.60

≥15 reps×1.10

Precisión real
Sin monitor cardíaco, el error es ±25–30%. El modelo es razonablemente honesto dentro de esa banda. No sobreestima como las maquinas de cardio comerciales (que inflan ~40%). Es un estimador consistente, no una medición.

08 · Flujo de trabajo con IA

Cómo se logea todo

No hay formularios en la UI. El ingreso de datos es 100% conversacional. Lean describe en lenguaje natural lo que comió o entrenó, y Claude Code lo parsea y escribe en el JSON.

Lean escribe en chat
→
/nutricion o /gym
→
Script Node.js inline
→
JSON actualizado

Skill /nutricion

  • Todo en un solo script Bash/Node
  • Sin llamadas previas de lectura
  • Estima macros cuando no se conocen (estimado: true)
  • Datos de paquete → estimado: false
  • Recalcula totales_ventana sumando todas las comidas
  • Hora del sistema por defecto, acepta hora explícita
  • Soporta imágenes de WhatsApp como input
  • ref_id snake_case consistente por alimento

Skill /gym

  • Lee log.json + perfil.json para peso actual
  • Mergea en sesión existente del día si ya hay una
  • Orden cronológico descendente mantenido
  • Auto-detecta gimnasio (Casa por defecto sin máquinas)
  • Fuerza: sets con reps y peso; null si no se sabe
  • Cardio: MET normalizado del ejercicio descrito
  • Muestra estimación kcal al final con el peso actual

09 · Brechas y deuda técnica

Sin formularios en UI
Todo el ingreso es por IA. Si Claude Code no está disponible, no se puede logear nada. Riesgo de dependencia total.
13 sesiones sin gimnasio
Campo gimnasio vacío o "?". Afecta filtros futuros por lugar.
Fasting counter: días sin registro
Muestra ayuno extendido falso cuando hay gaps de datos. Solución parcial: placeholder vacío.
Proteína 5g bajo target
155g vs target mínimo 160g. No es urgente pero es sistemático.
Sin DB: escala limitada
Con >500 sesiones los JSON van a ser lentos de parsear. SQLite es el próximo paso natural.
Cardio "undefined" en datos
Un item de cardio con ejercicio: undefined. Calidad de dato.

10 · Qué sigue (perspectiva técnica y humana)

Lo que está funcionando bien

  • El tracking conversacional con IA es fluido — elimina la fricción de formularios
  • El cálculo MET es honesto y consistente (no sobreestima)
  • −5 kg en 51 días con distribución de entrenamiento muy pareja
  • La UI dark theme es legible y no distrae
  • El FastingCounter da información fisiológica real, no decorativa
  • Los skills /gym y /nutricion son rápidos y confiables

Oportunidades inmediatas

  • +5g proteína/día: el gap más pequeño con el mayor impacto en composición corporal
  • Skill para días sin registro: cortar el fasting ficticio en 1 comando
  • Diferenciación visual de ventanas sin datos vs con datos
  • Registrar el peso más frecuentemente: solo 10 datos en 51 días — más datos → mejor tendencia
  • Consistencia en gym de Lean: anotar gymnasio en sesiones faltantes
Perspectiva humana
Este tracker no es una app de fitness genérica. Es una bitácora personal construida exactamente a medida de cómo Lean piensa y registra su vida. La decisión de no tener formularios — y de hablarle a Claude en lenguaje natural — refleja que el objetivo es que el registro sea liviano, no que sea "correcto". La pérdida de 5 kg en 51 días con una frecuencia de entrenamiento excepcional (5.5 ses/semana) muestra que el sistema funciona donde más importa: en sostener el hábito.
